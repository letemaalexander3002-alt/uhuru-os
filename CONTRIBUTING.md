# Jinsi ya Kuchangia Uhuru OS

Asante kwa kupenda kuchangia mradi wa Uhuru OS! Mwongozo huu unaelezea jinsi
ya kutuma maboresho.

## Kabla ya kuanza

- Soma `GOVERNANCE.md` kuelewa jinsi maamuzi yanavyofanywa
- Soma `TRADEMARK.md` — msimbo ni huru (MIT), lakini jina/logo ni mali ya
  Letema Group Tech
- Kwa mabadiliko madogo (typo, hitilafu ndogo), tuma Pull Request moja kwa
  moja. Kwa mabadiliko makubwa (kipengele kipya, mabadiliko ya muundo), fungua
  **Issue** kwanza kujadili kabla ya kuandika msimbo

## Aina za michango inayohitajika

- **Tafsiri** — kuboresha au kukagua tafsiri ya Kiswahili (Awamu ya 4)
- **Madereva/vifaa** — kuripoti au kurekebisha vifaa vya Kitanzania visivyofanya
  kazi vizuri (WiFi, printa, n.k.)
- **QA/majaribio** — kujaribu ISO kwenye vifaa halisi na kuripoti matokeo
- **Branding** — mapendekezo ya kuboresha muonekano (kupitia Issue kwanza)
- **Documentation** — kuboresha maelezo ya usakinishaji na matumizi

## Mchakato wa Pull Request

1. Fork repo hii
2. Tengeneza branch mpya yenye jina linaloeleza mabadiliko (`fix-wifi-driver`,
   siyo `patch-1`)
3. Fanya mabadiliko, jaribu kwenye ISO yako mwenyewe kabla ya kutuma
4. Andika ujumbe wa commit ulio wazi (Kiswahili au Kiingereza, vyote
   vinakubalika)
5. Tuma Pull Request ukielezea: nini kimebadilika, kwa nini, na jinsi
   ulivyojaribu

## Ukaguzi

Pull Requests zote zinakaguliwa na msimamizi wa mradi (Alexander Eliud
Letema / Letema Group Tech) kabla ya ku-merge. Hii siyo kwa sababu ya
kutoamini michango — ni kuhakikisha uthabiti wa ISO kwa watumiaji wote.

## Maadili

Tunatarajia heshima na uvumilivu kwa wachangiaji wote, bila kujali kiwango
cha uzoefu. Uhuru OS ni mradi wa jamii ya Tanzania — kila mchango, mkubwa au
mdogo, una thamani.
